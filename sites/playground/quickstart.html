FROM PLAYGROUND TO REPEATABLE WORK

Five minutes with Sluice.

Python 3.11 or later. Run the same declared rules locally, with saved review evidence.

Install from the source checkout

git clone https://github.com/zodsapple/sluice.git
cd sluice
python -m pip install .

The CLI and packaged example require the version of the source containing this playground. On Windows, use py if your shell has no python command.

Run the included example

sluice demo --out quickstart
sluice run quickstart/spec.yaml quickstart/input.csv --out quickstart/output

Three synthetic deliveries reconcile to an independent total of 165.5 and a row count of 3. Change 100.125 to 100.129 and run into a new output directory to see validation stop the conversion.

Draft, review and approve

sluice prepare quickstart/input.csv --schema quickstart/schema.json --work quickstart/work
sluice review quickstart/work
sluice approve quickstart/work --by ana --reason "Checked mappings, scope and independent controls"
sluice convert quickstart/work --out quickstart/reviewed-output

Use python -m sluice if the installed command is not on your PATH. For your own files, inspect the saved questions and prompts, apply answers with sluice answer or edit the YAML. Human review confirms the mapping and scope; validation checks the declared constraints.

Changing the input, schema, spec or referenced files invalidates saved approval. The direct run command is available for already reviewed specs. See docs/workflow.md in the source for the schema format and full workflow.
